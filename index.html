Compress PDF

Reduce the size of a PDF to make it easier to store, attach to an email, or share online.

Compression is useful when a document is too large for a website upload or messaging service. Always check the output before sending an important document.

OCR PDF

OCR can help extract readable text from scanned document pages that do not contain normal selectable text.

Best results

Use clear, well-lit scans with readable characters. Recognition quality can vary with handwriting, blur, unusual fonts, and complex layouts.

Before downloading

Check the text position and page appearance after editing. For legally important documents, keep an unchanged original copy.

Add a visible text watermark to help label documents as drafts, copies, samples, or internal material.

Common questions

Using SMLOOP

Do I need an account?

No account is required for the tools that are currently available without sign-in.

Can I use SMLOOP on a phone?

Yes. The interface is designed to work on mobile and desktop browsers. File and browser limitations can vary by device.

Are all tools browser based?

Many SMLOOP tools are designed to process files in the browser. The site clearly identifies browser-based workflows, while some services may use external processing where required.

Should I keep my original file?

Yes. Keep an original copy when a document is important, because editing, conversion, compression, or OCR can change the output.
