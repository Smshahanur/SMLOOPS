How to Report a Broken File Issue

If a file fails to process, please specify: 1. The tool used (e.g. Merge, Compress, OCR)
2. Approximate file size and page count
3. Browser & operating system (e.g. Chrome on Windows, Safari on iOS)
4. Whether the file is password-protected.

Frequently Asked Questions Before Reaching Out

Do you have a copy of the document I processed on SMLOOPS?

No. Because SMLOOPS tools run 100% locally in your browser memory, your files are never transmitted to our servers. We do not have access to, nor do we store, any of your documents. If you lost a processed file, simply run the tool again on your local device.

Why did my large PDF fail or run slowly?

Client-side processing utilizes your device's available RAM and CPU. Very large PDFs (e.g., scanned books exceeding 100MB or thousands of pages) may exhaust browser memory limits, especially on mobile phones. Try closing background tabs or processing in smaller batches.

Is SMLOOPS completely free to use?

Yes. All current PDF, image, and document tools on SMLOOPS are provided free of charge, with zero registration or subscription required.
