What is PDF Merging & How Does SMLOOPS Do It?

In everyday administrative and professional tasks, documents frequently originate from disparate sources: a cover letter typed in Microsoft Word, a financial spreadsheet exported from Excel, and a government ID scanned on a physical office multifunction printer. Merging brings these isolated digital assets together into a unified document package with unified pagination.

Unlike traditional web converters that require uploading your confidential files to remote data centers, SMLOOPS executes document consolidation client-side in your web browser using the open-source PDF-Lib engine:

  • Byte Stream Ingestion: Each selected PDF is loaded into memory as an ArrayBuffer.
  • Object Tree Copying: The internal page dictionary, vector font definitions, color spaces, and graphical streams are cloned into a newly instantiated PDF catalog.
  • Cross-Reference Table Synthesis: Page indices are sequentially re-numbered and a unified cross-reference (xref) table is constructed.
  • Instant Client-Side Serialization: The finalized binary stream is saved directly to your local file system as a single file.

Your sensitive medical records, tax schedules, or proprietary intellectual property are never transmitted across the network.

Step-by-Step Merging Tutorial

  1. Select Two or More PDF Files

    Click "Launch Merge PDF Tool" and select the PDF files you wish to merge from your local folder. You can hold Ctrl/Cmd to select multiple files at once.

  2. Verify Sequence

    Ensure the files are ordered properly. If you need to rearrange individual pages after merging, you can also use our Reorder PDF tool.

  3. Execute Merge

    Click the "Merge PDFs" button. The client-side engine clones page objects in volatile RAM and builds the consolidated document.

  4. Save & Check the Combined File

    Your browser immediately triggers the download of the combined PDF. Open it in your default viewer to verify that every page appears in order.

Technical Limitations & Pro Tips

Technical Considerations:

  • Encrypted & Protected PDFs: If any source document is locked with an owner or user password, the browser cannot read its internal page tree. Unlock the file first using SMLOOPS Unlock PDF.
  • Interactive AcroForms: If two merged PDFs contain form fields with identical internal field names (e.g. both files have an input named full_name), values may collide. In such cases, flatten or print the form to standard PDF first.
  • Different Page Orientations: Merging preserves the native orientation and dimensions of each page (e.g., combining Letter portrait with A4 landscape).

Pro Tips:

  • File Naming Convention: Name your source files with leading numbers (e.g., 01-cover.pdf, 02-resume.pdf) to keep track of their arrangement easily.
  • Compressing After Merging: Merging several scanned files can result in a large total file size. Run the merged output through SMLOOPS Compress PDF to optimize it for email sharing.

Frequently Asked Questions

Can I merge PDF files on an iPhone or Android phone?

Yes. SMLOOPS runs entirely within your mobile browser (Safari, Chrome, Firefox). Simply tap the file selector, choose the documents from your Files app, and merge.

Does merging reduce image quality?

No. Merging performs lossless object cloning. Embedded images, vectors, and font subsets are copied byte-for-byte without re-compression.

Can I merge PDFs with password protection?

You must remove the password first using our Unlock tool so the browser engine can access the pages to merge them.
